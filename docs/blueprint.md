# **App Name**: Crédito Simples

## Core Features:

- Client Management: User-friendly interface for managing client information (name, contact, loan details, payment history).
- Dashboard Overview: Display of key metrics such as total loans, outstanding amounts, and payment trends in a concise and visual manner.
- Payment Reminders: Automated reminders via email and/or SMS for upcoming payments, reducing late payments.
- Secure Authentication: Secure storage of client data using Firebase Authentication, with options for email/password login.

## Style Guidelines:

- Primary color: A trustworthy blue (#3498db) for the primary interface elements.
- Secondary color: A calm gray (#ecf0f1) for backgrounds and secondary text.
- Accent: A vibrant green (#2ecc71) to indicate success and positive actions.
- Clean and intuitive design with clear sections for easy navigation.
- Use simple and recognizable icons for common actions.
- Subtle animations to provide feedback on user interactions.
